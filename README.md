# MT_IMU_Information
## 河北美泰电子科技有限公司-IMU产品相关资料

### 目录结构

- Examples：多种语言的示例程序，包含C语言(Stm32)、Matlab、Python
- MT_IMU Software for PC：美泰IMU通用上位机的相关资料，包含安装包、使用说明以及升级方法
- USB_Uart_Drivers：配套线束的驱动安装程序

### 快速开始

1. 安装驱动：从 `USB_Uart_Drivers` 文件夹安装 USB转串口驱动程序
2. 安装上位机：从`MT_IMU Software for PC`文件夹安装美泰IMU通用上位机，上位机的使用说明以及升级方法详见文件夹中的对应文件
3. 硬件连接：将产品配套的线束连接IMU产品和PC
4. 开始使用：打开美泰IMU通用上位机，参考使用说明进行数据读取、数据显示、曲线绘制、2D/3D姿态视图显示、固件升级、产品配置等操作

### 示例代码

提供多种语言的示例代码：

- C：STM32F411的示例程序，包含产品配置、数据解析
- Python：包含产品配置、数据解析的示例程序
- Matlab：包含读取使用串口工具或美泰IMU通用上位机记录的txt文件的示例程序
